# Odd repeat beside unm CLsat arrays = DarSat5 (revision, 17 Oct 2026, first look)

170 copies of the 118-letter DarSat5 unit found in 13 clean 2 kb flanks of unm CLsat arrays (ssearch36 vs the DarSat5 consensus, Additional file 4, iterative masking, hits >= 90 letters, 57 on the reverse strand).
Each unit is oriented to DarSat5 and cut at DarSat5 position 1, then aligned with MAFFT --auto together with the DarSat5 consensus (first sequence).
- darsat5_units_aligned.fa: 171 sequences, 121 columns, 2.5% gaps.
(An earlier version cut units at fixed 149/118 letters from TRF starts; that was badly phased and is replaced.)
Not CLsat on either strand. Source: KIT /data/V/toki/clsat_map/cleanflank/rep/
