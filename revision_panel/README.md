# CLsat revision: final species panel, cluster -> family table (DRAFT for the author's approval)

satpipe run on Monsoon (/scratch/sk4386/satpipe_final/run), stages 1-8, six assembly copies: valentini Draft, mixta Draft,
D. unisexualis father/mother copies, D. armeniaca father/mother copies. 338 clusters, 6 347 rotated monomers.
Draft assignment by tests/darevskia/recurate_from_catalogue.py (the rules used to rebuild the published table):
a cluster whose centroid is >= 95 % identical to a family consensus over >= 100 bits takes that family; otherwise the
majority family of the read-checked loci its members lie in (>= 60 % of members inside loci, >= 60 % agreeing).
Each alignment: family consensus first, then the cluster's units, each turned to the consensus strand and rotated to start at consensus position 1 (best ssearch36 hit against the doubled consensus), then MAFFT --auto. A first version without this phasing looked random (39-54% identity) for 9 clusters and was replaced. Clusters 0 and 11 contain double units (292 letters).
All other clusters (largest 258 members) score only 14-21 bits against any CLsat consensus and stay unassigned.
