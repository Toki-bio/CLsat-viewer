# Amazon molly satellite families (provisional)

Units of tandem repeats (80-300 bp unit, at least 10 copies) found by Tandem Repeats Finder in the two
2021 haplotype assemblies of the Amazon molly (*Poecilia formosa*) in GenBank:
`lat` = GCA_013036135.2 (copy inherited from the *P. latipinna* father),
`mex` = GCA_013036085.2 (copy inherited from the *P. mexicana* mother).
Units from both copies were pooled and grouped at 90% identity (VSEARCH), then aligned with MAFFT
(--localpair --maxiterate 1000 --ep 0.123), the settings of the CLsat workflow. Each sequence name starts
with `lat|` or `mex|`. Only groups with 3 or more units are listed.

File name: `molly_famNNN_n<units>_lat<from latipinna copy>_mex<from mexicana copy>_unit<mean unit length>bp.fa`.

Provisional: based on the older 2021 assemblies (PacBio CLR reads); to be redone on new assemblies built from HiFi reads.
