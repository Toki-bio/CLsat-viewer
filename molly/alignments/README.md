# Amazon molly tandem-repeat families (provisional)

Tandem repeats (80-300 bp unit, at least 10 copies) found by Tandem Repeats Finder in the two 2021 haplotype
assemblies of the Amazon molly (*Poecilia formosa*) in GenBank: `lat` = GCA_013036135.2 (copy inherited from
the *P. latipinna* father), `mex` = GCA_013036085.2 (copy inherited from the *P. mexicana* mother).

Processed with the CLsat workflow (https://github.com/Toki-bio/CLsat_workflow) unchanged: Steps 3-7 within
each copy (motif extraction, simple-repeat filter, canonical rotation, 90% clustering, MAFFT alignment and
phase correction), then Step 8 (pool the phased members of both copies, degap, cluster at 90%), then Step 7
again on each pooled family so that all units start at the same position. Sequence names start with
`lat|` or `mex|`. Families with 3 or more units are listed.

Note: families with an 83-84 bp unit contain the zinc-finger linker motif (CACTGGTGAAAAGCC, encoding TGEKP);
they are probably arrays of zinc-finger gene repeats, not satellite DNA.

Provisional: based on the older 2021 assemblies (PacBio CLR reads); to be redone on new assemblies built from HiFi reads.
